# RUBENS

Software for the Motor Brush drawing machine: draw brush strokes, pick eight
drops of paint, preview the result, then let the machine run the brush.

Программа для машины Motor Brush. Рисуешь мазки, подбираешь восемь капель
краски, смотришь превью — машина ведёт кисть по холсту.
